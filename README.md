# Sekiro: Shadows Read Twice

A save analyzer for Sekiro: Shadows Die Twice

## Features 
  - Track missing Bosses, Prayer Beads, Gourd Seeds, and Headless
  - Track Prosthetic Upgrades and Esoteric Texts
  - View save stats (Playtime, XP, Sen, Vitality, Attack Power)
  - Clone save slots for backup

## Downloads
    Latest versions for Windows and Linux are available on the [Releases](https://github.com/melloXIII/sekiro-save-analyzer/releases/latest) page.


## Usage
Take your Sekiro save file, load it up, and see what you're missing to complete it!
